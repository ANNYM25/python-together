# Algorithms

Original teaching implementations. They're here so you can see the moving parts,
not to replace `list.sort` in production. Each notebook ends with a `✔️ Quick
check` cell of `assert`s, so running it top to bottom confirms it's correct.

| Notebook | Idea |
| --- | --- |
| `01_search.ipynb` | Linear and binary search; intro to Big-O |
| `02_sort.ipynb` | Merge sort and quicksort; divide and conquer |
| `03_recursion.ipynb` | Recursion and a bit of dynamic programming |
| `04_linked_list.ipynb` | Singly linked list from scratch |
| `05_stack_queue.ipynb` | LIFO stacks and FIFO queues |
| `06_graphs_intro.ipynb` | BFS / DFS on an adjacency list |
