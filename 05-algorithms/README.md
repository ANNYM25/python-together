# Algorithms

Original teaching implementations. They are here so you can see the moving parts, not to replace `list.sort` in production.

| File | Idea |
| --- | --- |
| `search.py` | Linear and binary search |
| `sort.py` | Merge sort and a simple quicksort |
| `linked_list.py` | Singly linked list |
| `stack_queue.py` | LIFO and FIFO |
| `recursion.py` | Recursion and a bit of dynamic programming |
| `graphs_intro.py` | BFS / DFS on an adjacency list |

Tests: `pytest 05-algorithms/tests`.
