# Start here

**Fastest path (no install):** open `01-python-foundations/01_hello_and_types.ipynb`
on GitHub and click the **Open in Colab** badge. Run the first cell. You're coding.

**Local path:** install Python 3.11+, create a virtual environment (see the
top-level README and `docs/setup-jupyter.md`), then `jupyter lab` and open the
same notebook.

Then:
1. Walk the tracks in order — each lesson's last cell points to the next.
2. Do the `🏋️ Your turn` cell every time; that's where it sticks.
3. Jot one line in `progress/PROGRESS.md` after each lesson.

You don't need to finish a folder in a day. Foundations before algorithms.
Mathematics before machine learning. Money math before ESG scoring.
See `how_we_learn.md` for the loop we use.
