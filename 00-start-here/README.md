# Start here

1. Install Python 3.11 or newer.
2. Create a virtual environment at the repo root (see the top-level README).
3. Run `python 01-python-foundations/01_hello_and_types.py`.
4. Write one line in `progress/PROGRESS.md` after each lesson.

You do not need to finish a folder in a single day. Foundations before algorithms. Mathematics before machine learning. Money math before ESG scoring.
