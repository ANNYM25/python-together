# How we learn in this lab

Read a lesson. Run it. Change a number. Break it on purpose. Then do `YOUR TURN`.

A useful loop for both of you:

1. **Predict** what the printout will be
2. **Run** the file
3. **Explain** the result in one sentence in `progress/PROGRESS.md`
4. **Reuse** the idea in a finance or ML toy (even a tiny one)

Annie can always replace a list of integers with a list of daily returns. The CS/ML track can always replace a finance formula with a vector and a plot. That is the point of sharing one repo.
